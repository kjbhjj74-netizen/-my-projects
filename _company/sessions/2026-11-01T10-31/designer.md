## 🎬 영상 템플릿 비주얼 시스템 최종 가이드라인 및 자동화 기술 요구사항

CEO님 지시에 따라, 확정된 콘텐츠 표준 포맷(SOP)을 기반으로 영상 템플릿에 적용될 비주얼 요소 가이드라인을 최종 확정하고, 이를 자동화 시스템에 반영하기 위한 기술적 요구사항 초안을 제시합니다.

### 1. 🎨 비주얼 시스템 최종 확정 (The Visual DNA)

**브랜드 톤:** 친근함과 신뢰감 (Friendly & Trustworthy)
**스타일 레퍼런스:** 미스터비스트 (Mistvisited) 스타일의 역동성과 정보 전달력을 결합.

#### 1.1. 컬러 팔레트 (Color Palette)
시청자의 집중도를 높이고 브랜드 정체성을 확립하는 핵심 컬러입니다.

| 역할 | 컬러 이름 | HEX 코드 | 사용 목적 |
| :--- | :--- | :--- | :--- |
| **메인 컬러 (Primary)** | Deep Teal (깊은 청록) | `#007979` | 배경, 주요 제목 강조, 신뢰감 부여 |
| **액센트 컬러 (Accent)** | Vibrant Orange (생동감 있는 주황) | `#FF6B35` | 후크 문구 강조, CTA 버튼, 중요한 데이터 시각화 |
| **배경 컬러 (Background)** | Soft Off-White | `#F5F5F5` | 텍스트 가독성 확보, 친근하고 깔끔한 느낌 제공 |
| **보조 컬러 (Secondary)** | Dark Gray | `#333333` | 본문 텍스트, 보조 정보, 썸네일 대비 |

#### 1.2. 타이포그래피 스타일 (Typography Style)
친근함과 정보 전달력을 동시에 확보하는 폰트 조합입니다.

*   **제목/후크 (Headline/Hook):** **Pretendard Bold** (또는 유사한 고딕 계열의 굵은 산세리프체).
    *   **용도:** 영상 도입부(Hook) 문구, 핵심 메시지 강조.
    *   **스타일:** 굵고 시선을 사로잡으며, 액센트 컬러(`#FF6B35`)를 사용하여 역동성 부여.
*   **본문/설명 (Body/Description):** **Noto Sans KR Regular/Medium** (또는 유사한 가독성 높은 산세리프체).
    *   **용도:** 본론 설명, 자막, 영상 설명란.
    *   **스타일:** 깔끔하고 읽기 쉬우며, 메인 컬러(`#007979`)를 사용하여 신뢰감을 유지.

#### 1.3. 필수 구성 요소 (Essential Components)
모든 영상 템플릿에 반드시 포함되어야 할 구조적 요소입니다.

1.  **오프닝 훅 (Opening Hook Zone):** 영상 시작 5초 이내에 시청자의 시선을 강탈하는 텍스트 오버레이 영역. (액센트 컬러 사용 필수)
2.  **핵심 메시지 박스 (Key Takeaway Box):** 영상 중 중요한 정보가 나올 때, 배경색(`#007979`)을 활용한 박스 형태로 강조.
3.  **화면 전환 (Transition Style):** 정보 전달 시에는 깔끔한 '와이프(Wipe)' 또는 '슬라이드(Slide)' 전환을 사용하며, 감정적 클라이맥스 시에는 빠르고 역동적인 '줌 인/아웃(Zoom In/Out)' 효과를 병행.
4.  **CTA 영역 (Call To Action Footer):** 영상 마지막 10초에 고정되는 구독/좋아요 유도 애니메이션 및 텍스트 영역.

### 2. ⚙️ 자동화 시스템 반영을 위한 기술적 요구사항 초안

위에서 확정된 비주얼 가이드라인은 향후 콘텐츠 제작 자동화 트리거가 작동할 때, 디자인 시스템에 직접적으로 반영되어야 합니다.

| 단계 | 요구사항 | 기술적 구현 방법 (API/Tooling) | 담당 에이전트 |
| :--- | :--- | :--- | :--- |
| **1. 템플릿 생성** | **디자인 에셋 자동 삽입** | **Figma API 연동:** 확정된 컬러 팔레트(HEX)와 폰트 스타일(Font Family)을 기반으로, 템플릿 파일(Figma/After Effects 템플릿)을 자동으로 생성/업데이트하는 스크립트 구축. | Designer |
| **2. 스크립트-비주얼 매핑** | **Scene-Visual Mapping Engine** | **JSON/YAML 데이터 구조화:** Writer가 생성한 최종 스크립트(`.txt` 또는 `.md`) 내의 특정 키워드(예: `[HOOK]`, `[KEY_POINT]`)를 인식하여, 이에 매핑되는 비주얼 요소(예: `Type: Headline`, `Color: #FF6B35`)를 자동으로 추출하는 로직 개발. | Writer, Designer |
| **3. 썸네일 생성** | **CTR 최적화 자동 생성** | **AI Image Generation API 연동:** P1.3에서 확정된 썸네일 컨셉 3안을 기반으로, 확정된 컬러 팔레트와 타이포그래피 스타일을 강제 적용하여 썸네일 이미지 초안을 대량 생성. | Designer |
| **4. 최종 검증 (Validation)** | **Visual Compliance Check** | **Post-Production Check:** 최종 편집 단계에서, 영상 템플릿이 확정된 가이드라인(예: 오프닝 5초 내 액센트 컬러 사용 여부)을 위반할 경우, 자동 경고(Alert)를 발생시키는 검증 모듈 추가. | Secretary (Automation Layer) |

📊 평가: 완료 — CEO 지시사항(비주얼 가이드라인 확정 및 기술 요구사항 초안 작성)이 구체적이고 실행 가능한 형태로 도출되었으며, 자동화 시스템 연동 방안까지 제시되었습니다.
